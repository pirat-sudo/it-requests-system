## Автоматизированные тесты

Запуск: `cd backend && npm test`

Покрывают: авторизацию, CRUD заявок, фильтры, поиск, комментарии, права ролей, удаление.

## Найденные ошибки и исправления

| Ошибка | Исправление |
|--------|-------------|
| Не было endpoint GET `/api/requests/:id` | Добавлен endpoint, фронт использует `getRequest()` |
| Отсутствовала таблица категорий | Добавлена таблица `categories`, поле `category_id` в заявках |
| API URL был захардкожен на localhost | Используется `window.location.origin` |
| CI запускал `npm test \|\| echo` без реальных тестов | Добавлены supertest-тесты и workflow `ci.yml` |
| Логин принимал password123 для любого пользователя без проверки хеша | Исправлена проверка пароля в `app.js` |
